【4. 按验签器全局窗计划生成 acoustic-NN.bin（R2）】
常量（与 bandroom_acoustic.acoustic_stage 完全一致）：frameSamples=320、receptiveSamples=400、windowFrames=800、contextFrames=100、offsets=(0,400)、features=768。plan 由解码 sampleCount 推导：
  total=(sampleCount-400)//320+1；
  对 offset∈{0,400}：first 从 (offset-800 if offset else 0) 开始、步长 800；start=max(0,first)、end=min(total,first+800)、left=max(0,start-100)、right=min(total,end+100)。
对每个 window：
  startSample=left*320；endSample=(right-1)*320+400；pcm=s16[startSample:endSample]/32768 转 float32；
  encoder.run(["features"],{"samples":pcm[None]})；断言 shape=(1,right-left,768)、float32、有限；
  raw=features[0,start-left:end-left].astype("<f4").tobytes()；长度必须=(end-start)*768*4。
  identity={environment:<release environmentId>,taskId,attemptId,revision,inputSha256:recordingSha256,inputBytes:441322,decodeSha256:<checkpoint SHA>,bundleSha256:<runtimeBundleSha256>,configSha256:sha256(canonical analysis-config.json.acousticConfig)}。`analysis-config.json` 从 /mnt/data/bandroom-g5/analysis-config.json 读取并经 SHA 校验；取不到则停止，不得自造。

  写 `acoustic-00.bin…acoustic-NN.bin`；断言 chunk 数=len(plan)（HJK 预期 10）、≤24、digest 互异。
