# Roadmap

## Near term (evidence-gated, not engineering-gated)

- **T2 personal calibration** — accumulates as the learner uses the site and answers three-state self-listen verdicts across sessions. V3-P requires ≥4 sessions and sufficient future candidates; thresholds are fixed and not lowered. No data is fabricated.
- **Observation windows** — each production change opens a 24h window; verdicts only at/after the scheduled end.

## Independent projects (require owner resources)

- **G1 formal blind test** — browser-native corpus + two annotators + adjudicator.
- **G5 formal signing** — G0–G4 + formal build + formal identity + four Ed25519 keys + 24h + full M4 timing.

## Possible later work

- Commercial-safe encoder/corpus swap if licensing scope changes (currently personal/non-commercial; L2-ARCTIC CC BY-NC, weights not distributed).
- Per-user T2 default-on only after V3-G cross-user evidence (≥6 users).
