# G1 重构方案评审与闭环

日期：2026-11-19 · 对象：`G1_RESTRUCTURE_DESIGN.md`（SHA 2ff18caa）
方法：主导自查 + 两路独立对抗视角（效度视角 / 可复现与治理视角），逐条裁决（接受/部分接受/驳回）。**全部接受或部分接受，无驳回**。结论见 §裁决汇总；rev2 见 `G1_RESTRUCTURE_DESIGN.md`。

## 一、评审发现

### 阻塞（BL）
- **BL1 机器一致性≠效度，κ 不能当门。** 面板可高置信地错（omni-plus 曾以 0.95 置信把正确发音判错）。Fleiss κ 受类别流行度影响（本会话实测：近一致却 κ=0.25）。→ **接受**：一致性（within-1）仅作「必要非充分」门；**效度由客观锚点承担**；κ 仅描述性，不作阈值；PASS 必须锚点覆盖达标。
- **BL2 L2 非劣效在 4 v 7 未配对样本上不成立。** 欠功效 + 基线（Work 历史反馈）与 Qwen 样本 attempt/语境不同，混杂无法用边际修正；宽 CI 下「下界≥−边际」既可能假过也可能假败。→ **接受**：L2 降级为**描述性估计+CI**，不授予非劣效声明；仅当存在配对/足够样本并另行预注册时才恢复 NI 判定。PASS 不依赖 L2 的 NI。
- **BL3 音频评审同家族，「跨家族」声称虚假。** 音频教练 omni-plus、评审 omni-flash：同家族异档。→ **接受**：明示音频独立性有限；**音频层不声称跨家族**；claim scope 收窄；音频结论仅作 evidence，不单独支撑 PASS。
- **BL4 critical 聚合无多数规则。** 原设计只要任一评审 critical 即计入，单评审即可否决。→ **接受**：critical 需 **≥2 评审**或仲裁确认；单评审 critical 记 advisory。
- **BL5 仲裁闭环与形状归一。** AG1 曾有 arbiter 返回 `scores` 而非 `score` 导致三版 arbiter 从未生效。→ **接受**：仲裁显式归一（含 `scores[dim]` 回退）；unresolved（含仲裁仍>1 分歧）→ ESCALATE。
- **BL6 重跑/可选停止=verdict shopping。** 自动面板换 seed/模型可翻结论。→ **接受**：**单次预注册分析**；冻结面板/seed/模型版本/阈值；重评须新预注册 + 归档旧判定 + 终止承诺（测不到≠不合格）。

### 重大（MJ）
- **MJ1 锚点覆盖不足。** 仅 HJK 单词语料。→ **接受**：明确锚点覆盖集（HJK 真值 + 引文核验 + 校准韵律）；PASS 要求锚点覆盖达标；覆盖不足标 `anchor_coverage=partial` 且不得 PASS。
- **MJ2 引文核验软阈值区分不足。** 引号内可能是「建议更正」而非学习者原话。→ **接受**：预注册区分 learner-quote 与 suggested-correction（结构化标记）；仅 learner-quote 参与虚构判定。
- **MJ3 owner 作为最终裁决存在利益冲突。** → **接受（部分）**：owner 仅做**矛盾 sanity**（与面板 critical 冲突时升级人工复核），**不可把 FAIL 改判 PASS**。
- **MJ4 去重规则不确定。** → **接受**：按内容哈希保留最早样本、丢弃后者并记录 `dropped_duplicate`；规则确定性、可复现。
- **MJ5 未报功效/样本量。** 4 样本无功效。→ **接受**：报告 n、CI 宽度；标注 `underpowered`；不足时 PASS 仅标「指示性」，不得对外作达标声明。
- **MJ6 L3 单模型红队。** → **接受**：红队结论须有可演示证据（引文/音素/语法）或第二家族佐证，否则仅 advisory，不单独否决。
- **MJ7 模型别名漂移/不可复现。** → **接受**：封存实际模型 id、请求/响应、响应 hash、时间；报告含模型版本。
- **MJ8 音频 critical 归口。** → **接受**：音频 critical 仅由独立音频评审给出；文本评审不得因「听不到音频」判 critical。
- **MJ9 标签误读风险。** PASS 可能被读成人工门。→ **接受**：报告与对外文档固定标签 `G1-automated(machine-panel)` + `claim_scope`，明示非人工标注门。

### 次要（mn）
- **mn1** within-1=0.7 为经验阈值 → 标注「经验、无功效依据」。
- **mn2** 百分位 bootstrap 小样本偏窄 → 改 **BCa** 或标注保守性不足。
- **mn3** 锚点正则脆弱 → 结构化时间解析（词→时间需同一子句）。
- **mn4** 封存需含 SHA256SUMS + prompts + model ids + raw。
- **mn5** 缺 truth/audio 应 fail-closed，不得 PASS。
- **mn6** 报告同时呈现 `human_annotators=0` 与 `owner_anchor`。
- **mn7** 需 owner 抽查模板与预注册子集（三态/评分）。

## 二、裁决汇总
- 接受：BL1–BL6、MJ1–MJ2、MJ4–MJ9、mn1–mn7。
- 部分接受：MJ3（owner 仅 sanity，不可改判）。
- 驳回：无。
- 核心变化：**一致性≠效度**（锚点承担效度）；**L2 不再授予 NI**；**音频不声称跨家族**；**单次预注册、禁止 verdict shopping**；**critical 多数规则**；**underpowered 标注**；**标签定为机器面板**。
